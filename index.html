      How to read the stages

      Open PR earmark
      Value of purchase requisitions released against the budget but not yet converted to a PO (value type 50).
      Open PO commitment
      PO value not yet received or invoiced (value type 51). It drops as GRs and invoices are posted.
      Actuals booked
      Goods receipts awaiting invoice plus invoices posted through MIRO or FI (value type 54). This is spend already incurred.
      Carry-forward
      Open FY 2025-26 PRs and POs moved into this year on 1 Apr 2026, and every follow-on posting against them.

      Open PO value by age

      Age counted from the PO document date to 28 Oct 2026.

      Open PR value by age

      Age counted from the PR document date to 28 Oct 2026. PRs over 90 days are the follow-up list for buyers.
